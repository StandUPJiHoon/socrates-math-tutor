# 수크라테스 분수 튜터

초등학교 6학년 분수의 나눗셈 학습을 위한 React/Vite 앱입니다.

## 실행 방법

1. Node.js를 설치합니다.
2. 의존성을 설치합니다.

```bash
npm install
```

3. 개발 서버를 실행합니다.

```bash
npm run dev
```

4. 배포용 파일을 만듭니다.

```bash
npm run build
```

## 현재 상태

이번 작업은 기존에 붙여넣은 React 코드를 Vite 프로젝트에서 실행 가능하게 구성하는 단계입니다.
Firebase, Apps Script, Gemini 연결은 아직 추가하지 않았습니다.
