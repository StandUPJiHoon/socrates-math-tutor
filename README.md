# Socrates Math Tutor

React/Vite app for the Socrates fraction tutor prototype.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Current Scope

This version only wires the existing React app into Vite so it can run in the browser.

Apps Script, Gemini, and Google Sheets integrations are not included yet.
